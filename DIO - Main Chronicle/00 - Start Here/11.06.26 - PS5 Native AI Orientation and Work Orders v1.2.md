## 1. One North Star

> **Independently verify a useful AI inference workload executing locally on the user's original-model PlayStation 5 itself, without offloading model computation to a computer or cloud service, through a technically evidenced native-execution path, with human authorization and independently qualified safety/evidence boundaries before any device intervention.**

**Success is not:** a cloud model answering through Remote Play; an external Mac reading HDMI; a GitHub-hosted Linux demonstration; merely unlocking a browser; merely decrypting a PUP; an exploit or an installed Linux environment without local AI inference; source-level assertions without a PS5-local observation.

**Success would require:** the model files and computation actually resident/running on PS5 hardware; identifiable code/runtime/process evidence; an independently assessed output from a specified local prompt or synthetic workload; on-console resource observations; no inference delegation to an external endpoint. The proof method, measurement bounds and risk approval must be frozen **before** any future authorized run.

## 3. Dependency chain and discrete qualifications

```text
S0   Verified target hardware and exact firmware — UNKNOWN on physical device
 |
S1   Proven locally executable code path on that exact firmware — BLOCKED/UNKNOWN
 |
S2   Usable PS5-local runtime and memory APIs — NOT ESTABLISHED
 |
S3   CPU model inference proof (small and measurable) — NOT RUN
 |
S4   Optional GPU acceleration / larger models — NOT ESTABLISHED
 |
S5   Qualified independent custody, STOP, recovery + human permission — NOT BUILT
 |
S6   Verified local, offline, repeatable inference on PS5 — NOT RUN
```

Dependencies are logical, not an authorization to proceed from one gate to the next. Safety/authority review must precede any actual device action, even a small S3 demonstration.

**Important experimental design:** a small genuine neural-network inference on the PS5 CPU would be a valid early on-device proof, if a legitimate executable environment were available. A larger language model is a later performance milestone; an abstract menu-state machine or shell script alone is **not** neural inference. Begin CPU-first to decouple code execution from GPU-driver uncertainties; do not mistake CPU-first for proof that a CPU runtime already works.

## 6. Scientific and evidence policy

Record each inquiry as **condition → directly observed source behavior → supported relationship → inference/prediction**. Log null results, capability refusals, provenance gaps, version mismatches and abandoned avenues. Old BLOCK verdicts remain immutable when a newer source repair passes. Each claimed advancement needs a pinned source, commit/blob, date, specific test or public evidence, reviewer independence statement and no hidden scope expansion.

**DIO's role:** independent falsification, not a guard, jailbreaker or operator. Ask DIO at meaningful milestones whether each candidate genuinely moves computation **inside** the PS5, which evidence is authentic, and which trust boundary prevents permission escalation. An issue handoff does not itself invoke DIO.
