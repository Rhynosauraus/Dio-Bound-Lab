## Legitimate decision alternatives (no work authorized)

**A. Preserve target retail PS5 on reported 14.22 and continue source-only inquiry.** Best fit for the human's exact original-machine North Star. Progress may be bounded until a valid same-firmware local execution path emerges. Public WebKit/OSS analysis is not native entry.

**B. Separately use an older-firmware compatible PS5 in the future (only if the human independently chooses and authorizes acquisition).** Stronger chance of eventual native Linux/CPU inference on *PS5 hardware*, but does not establish a way into the user's current 14.22 console, and entails new costs, sourcing risks and device tests. Do **not** claim downgrading the current console is viable.

**C. Explore licensed PlayStation Partners/approved dev hardware.** A distinct official development route, contingent on partner eligibility, purpose, agreements and possibly returning hardware. Cannot claim it works for the original retail PS5 or that any applicant will be accepted. No application submitted.

**D. Run the toy inference design on an ordinary Linux PC only as a later separately authorized *off-console software* test.** Helps debug model semantics but proves **nothing** about PS5 access or execution.

## Gate to change this verdict

A future source or independently authenticated observation must establish, *on the exact target firmware*:
1. Provenance: precise version, model, code/artifact commit, method and documented access prerequisites;
2. Actual permitted local execution environment—not just a browser or menu/UI flag;
3. Available CPU memory, data loading and output path, with their technical limits;
4. Independent source and risk review, plus explicit human consent **before any device action**;
5. A separately defined measured neural inference proof with no off-device inference.

Until then: **NATIVE-WO-001: SOURCE REVIEW COMPLETE; 14.22 EXECUTION PATH BLOCKED/UNKNOWN, NATIVE RUNTIME NOT RUN, SECURITY/CONTAINMENT NOT QUALIFIED.**
