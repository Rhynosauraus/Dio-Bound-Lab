## 2. Causal replay contract

The v0.2 `MockEvent` preserved action, proposal reference, kind and frame digest but not enough structure to reconstruct current state or enforce review/proposal relationships. The new v0.3 event source adds:

- `frame_sequence` to bind each event to the accepted synthetic frame sequence;
- `available_actions` **only** on OBSERVED events, to reconstruct current mock affordances;
- `local_capacity_halt` in the in-memory state, true only for unrecorded refusal at the 64-event cap.

A new pure `_replay_local_history` procedure starts at an empty synthetic state and walks the supplied event tuple. It checks the sequential row numbers and field types, reconstructs latest observed frame digest/actions, pending Proposal, and local STOP state, then compares that reconstruction to the supplied `MockState` fields. This yields a **syntax/causality claim**, not a genuine trusted log.

Expected model invariants (source expectations; no tests executed):

| Event | Local consistency rule |
| --- | --- |
| OBSERVED | Increasing positive mock frame sequence, well-shaped digest, nonempty unique allowed abstract actions; invalidates prior pending |
| PROPOSED | One pending at a time, bound to observed seq/digest and offered action; no reused proposal identifier |
| REVIEW_APPROVE/DENY/STOP_CLAIM | Requires matching current pending, same abstract action and proposal identifier, no reused decision identifier; STOP marks modeled stopped |
| STOPPED | Only before a prior STOP; clears pending; modeled event, not external effect/kill |
| REFUSED | Does not change frame/pending/stopped; its row metadata must match reconstructed current frame |
| Event capacity | At 64 rows, return `EVIDENCE_LIMIT_STOP`, `recorded_in_model=False` and local stopped state with `local_capacity_halt=True`; **no new event or durable STOP receipt exists** |
| Malformed state | `EVIDENCE_GAP_STOP`; original malformed state returned unmodified, without a new event or a durable stop |

The `local_capacity_halt` special case is necessary because an event-cap refusal cannot be reconstructed from **nonexistent** new evidence. It is a caller-owned local flag, and an adversary can discard it or substitute a consistent earlier state. **STOP rollback protection is absent by design.**
