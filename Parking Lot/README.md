# Parking Lot

A holding area for questions worth retaining but **not yet authorized, prioritized, or qualified** for execution. Parking an idea is not evidence that its premise is true. This is distinct from the existing [Hypothesized Abilities](../Hypothesized%20Abilities/README.md) directory, which stores proposed capabilities for future tests.

Each parked question should identify its provenance, competing explanations, a bounded discriminating experiment, an owner/decision gate, and a trigger for reconsideration. No execution is implied.
